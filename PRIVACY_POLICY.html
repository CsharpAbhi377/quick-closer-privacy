Privacy Policy — Zendesk Quick Closer

Last updated: 12 May 2026

The short version: Zendesk Quick Closer does not collect, transmit, or store any data outside of your own browser. There are no network calls, no telemetry, no analytics, no third-party services. Every byte of data the extension uses stays on your computer.

What data the extension handles

The extension reads and interacts with the following information, strictly on the user's local computer:

  • Zendesk form fields — when you click "Apply" or "Read options from page," the extension reads the labels and dropdown options of the ticket form on your currently active Zendesk tab. This is used to identify which form fields to fill.
  • Preset configurations — the named presets you create are stored locally in chrome.storage.local.
  • Cached dropdown options — to populate the extension's own dropdowns without requiring re-scan each time.
  • Usage statistics — a count of how many times each preset has been applied, stored locally. Used to populate the Stats tab. Capped at 2,000 events.
  • Last-applied selections and floating-button position — UI state remembered between sessions.

What the extension does NOT do

  • It does not read ticket comments, customer information, ticket subject, ticket body, or any other content outside of the form's dropdown field labels.
  • It does not make any network requests to any server, ever. No analytics. No crash reporting. No update pings.
  • It does not use cookies, third-party scripts, or remote resources.
  • It does not share data with the developer, HotDoc, Anthropic, or any other party.

Data export and deletion

You can export your local usage statistics as a CSV file via the Stats tab. You can clear all stats via the same tab. You can export and import presets as JSON via the Presets tab. Uninstalling the extension removes all extension data from your browser.

Permissions used

  • storage — to save your presets and settings.
  • activeTab — to read the active Zendesk tab's form structure when you click Apply.
  • scripting — to re-inject the content script after extension updates.
  • host_permissions: *.zendesk.com — the extension only operates on Zendesk Agent pages.

Children's privacy

This is a B2B productivity tool intended for adult support agents. It is not directed at children.

Changes to this policy

If this policy changes, the updated version will replace this page and the "Last updated" date above will reflect the change.
